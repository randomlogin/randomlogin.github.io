This is the first post. To publish a new finding, drop a Markdown file into the
`_posts/` directory named `YYYY-MM-DD-some-title.md`, with this front matter at
the top:

```yaml
---
layout: post
title: "Your title here"
date: 2026-06-30
---
```

Everything below the front matter is the body, written in Markdown. Math, code
blocks, links — all the usual Markdown works. The post will automatically show
up on the [blog index](/blog/) and in the RSS feed, newest first.
